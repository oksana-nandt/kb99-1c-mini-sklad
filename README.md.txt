# kb99-1c-mini-sklad

Учебная конфигурация «Мини-Склад» для платформы 1С:Предприятие 8.3.  
Минимальный контур учёта: справочники (Товары, Контрагенты), документы (Поступление, Реализация), регистр накопления «ОстаткиТоваров», интерфейс в подсистеме «Мини-Склад».

## Структура

- `src/` — выгрузка конфигурации в XML (исходники объектов).
- `docs/` — документация, схемы, скриншоты (если есть).

## Как открыть в Конфигураторе

1. Создать пустую базу 1С.
2. Открыть Конфигуратор.
3. Меню: **Конфигурация → Загрузить конфигурацию из файлов…**
4. Указать папку `src/`.
5. Обновить конфигурацию базы данных (F7).
6. Запустить в режиме Предприятия.

## Версионирование

Конфигурация хранится в виде XML‑выгрузки для контроля версий в Git.  
Не коммитьте файлы `.cf`, `.dt`, кэш и временные файлы — они исключены в `.gitignore`.

## Лицензия

Учебный проект, свободное использование в образовательных целях.
